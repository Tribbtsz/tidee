# tidee

把 Edge 收藏夹理干净：自动分类、写一句人话描述、批量写回收藏夹。

不抓网页、不截图、不上传收藏夹。收藏结构通过 Edge 自带的账号同步出现在其他设备。

## 它解决什么

- 74 条收藏挤在一个 `ui` 文件夹里，只能靠标题猜内容
- 想找东西只能全打开
- 手动分类一次就再也不想维护

tidee 只读收藏的**标题和网址**，让模型给出分类和一句简短描述。整理结果写回 Edge 时只移动书签、创建文件夹，不改标题和网址。

## 安装

```powershell
pnpm install
pnpm build
```

然后：

1. 打开 `edge://extensions`
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」
4. 选择 `D:\MyFiles\tidee\.output\edge-mv3`
5. 把 tidee 固定到工具栏

> 未打包扩展依赖开发者模式。Edge 重启后如果发现它被禁用，在 `edge://extensions` 里重新启用即可。

## 配置模型

tidee 不内置任何服务商、API 地址、Key 或模型。点击工具栏图标会直接打开工作台，点左下角「设置」，自己填：

- **API 地址**：你的服务商提供的 OpenAI 兼容 Base URL，通常以 `/v1` 结尾
- **API Key**：对应的 Key
- **模型**：服务商控制台里的模型 ID

点「测试连接」。首次调用会请求该域名的访问权限，扩展只直接请求你填的地址，不经过 tidee 的中转。

## 使用

1. **读一遍**：默认只读没有描述的收藏；也可以只重读有问题的条目，或全部重读
2. **看待确认**：分类为空、描述太短或分类过旧的条目会进这里；手动改过的条目不会被“重读有问题的”覆盖
3. **写回**：选择「其他收藏夹」或「收藏夹栏」，默认只创建 5 个一级分类
4. **撤销**：工作台左下角设置 → 数据与备份，或再次打开写回弹窗
5. **卡片操作**：点卡片打开链接；铅笔编辑描述；更多菜单可重命名、复制链接、删除收藏
6. **自动整理**：设置里默认开启，新增书签约 1 分钟后自动处理；后台定时任务默认每天补漏。删除书签时，对应的 AI 描述也会清掉

写回前会自动下载一份可导入 Edge 的 HTML 备份。

## 分类

默认 5 个一级分类，外加系统兜底「未分类」：

| 分类 | 收纳 |
| --- | --- |
| 设计资源 | 设计灵感、作品集、UI 组件、图标、插画、配色、字体、模板 |
| AI 与开发 | AI 模型与助手、编程、框架、代码片段、开发者工具 |
| 阅读与资讯 | 个人与技术博客、周刊、文章、社交媒体、论坛、视频、新闻 |
| 效率工具 | 搜索引擎、邮箱、笔记、文档、协作和日常工具 |
| 生活服务 | 购物、餐饮、出行、影音、金融和生活服务 |

博客统一进「阅读与资讯」，不再按技术主题拆散。

二级分类默认只留在 tidee 内部，用于描述和搜索；想在 Edge 里也建二级文件夹，可以在设置或写回弹窗里打开。

## 技术栈

- **WXT 0.21**：Manifest V3 扩展框架，Vite 驱动
- **Vue 3.5 + TypeScript**
- **Tailwind CSS 4**
- `chrome.bookmarks`：读写收藏结构
- `chrome.storage.local`：保存设置、描述、撤销记录
- `fetch` 直连 OpenAI 兼容接口
- 无后端、无数据库、无截图服务

```
entrypoints/
  dashboard/     工作台（设置也在这里，单页切换）
  background.ts  工具栏图标点击入口
components/      界面组件
composables/     状态、主题
lib/             分类、AI 请求、书签操作、备份、规则
tests/           纯逻辑单元测试
```

## 数据与隐私

- 分类时只发送标题、网址，不再发送原文件夹名，避免 `ui` 这类旧文件夹带偏分类
- 不申请 `tabs`、`history`、`scripting`、`<all_urls>`
- 权限只有：`bookmarks`、`storage`、`favicon`；你填的模型域名在首次调用时按需申请，不预先写进 manifest
- API Key 存在本机 `chrome.storage.local`，不同步、不上传
- 描述和标签只在这台电脑的扩展里；文件夹结构跟随 Edge 账号同步
- 写回前自动下载 HTML 备份，并保留一次撤销记录

## 开发

```powershell
pnpm dev        # Edge 开发模式，热更新
pnpm compile    # vue-tsc 类型检查
pnpm test       # 纯逻辑单元测试
pnpm build      # 生产构建到 .output/edge-mv3
pnpm zip        # 打包
```

## 已知限制

- 小模型在冷门站点上偶尔会给出泛化甚至错误的描述；「待确认」目前只能覆盖分类缺失、描述过短和低置信度，无法识别所有幻觉。换更强的模型、或手动改几条，都比加抓取更直接。
- Edge 书签 API 没有「描述」字段，所以描述只存在 tidee 里，不会出现在 Edge 收藏夹中。
- 整理后的文件夹会同步到同一微软账号的其他设备。
- 未打包扩展需要开发者模式；重装或移动目录后需要重新加载。

## 实测

2026-10-20，125 条真实收藏：

- 测试时每批 20 条、2 路并发：7 次请求，约 35 秒，0 失败，约 1.7 万 tokens
- 分类结果：设计资源 59、阅读与资讯 35、效率工具 16、AI 与开发 12、生活服务 1、未分类 2
- 待确认 2 条
- 写回 125 条 → 5 个分类文件夹；撤销后全部回原位，空文件夹自动删除
- 备份 HTML 已生成并可导入 Edge
