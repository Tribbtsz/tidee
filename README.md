# tidee

一个用于整理 Microsoft Edge 收藏夹的本地扩展。

它读取收藏的标题和网址，借助兼容 OpenAI 接口的模型生成分类和简短描述，再把整理后的文件夹结构写回 Edge。不抓取网页、不截图、不上传收藏夹。

## 功能

- 自动分类：默认提供少量一级分类，可在设置中增删改
- 生成描述：为每条收藏写一句简短、可检索的说明
- 批量写回：创建分类文件夹并移动书签，不改标题和网址
- 手动编辑：支持修改分类、描述、标签，以及重命名、复制链接、删除收藏
- 自动整理：新增收藏后自动处理，也可按固定间隔补漏
- 可撤销：写回前自动备份，保留一次撤销记录
- 账号同步：文件夹结构通过 Edge 自带同步出现在其他设备

## 工作方式

1. 读取 Edge 收藏树
2. 按批次把标题和网址发送给模型
3. 模型返回分类、二级分类、描述和标签
4. 结果保存在扩展本地存储中
5. 需要时把分类结构写回 Edge 收藏夹

模型接口、地址和 Key 均由用户自行填写，扩展不内置任何服务商信息。

## 安装

```powershell
pnpm install
pnpm build
```

然后在 Edge 中：

1. 打开 `edge://extensions`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择构建输出目录 `.output/edge-mv3`
5. 将 tidee 固定到工具栏

> 未打包扩展依赖开发者模式。如果 Edge 更新后扩展被禁用，在 `edge://extensions` 重新启用即可。

## 配置

点击工具栏图标打开工作台，进入左下角「设置」：

- **API 地址**：OpenAI 兼容接口的 Base URL，通常以 `/v1` 结尾
- **API Key**：对应服务的访问密钥
- **模型**：服务商提供的模型 ID

点击「测试连接」验证配置。首次请求时会申请该域名的访问权限，扩展只直接请求填写的地址，不经过第三方中转。

## 使用

- **读一遍**：处理尚未生成描述的收藏
- **重读有问题的**：只处理未分类、描述过短或分类过旧的条目
- **全部重读**：覆盖所有描述和分类，包括手动修改
- **待确认**：集中查看需要人工检查的条目
- **写回**：选择目标位置，创建分类文件夹并移动书签
- **撤销**：恢复上一次写回操作
- **分类设置**：在设置里增删改一级分类；二级分类默认只保留在 tidee 内部

卡片支持直接操作：

- 点击卡片：打开收藏链接
- 铅笔按钮：编辑描述
- 更多菜单：打开、编辑、重命名、复制链接、删除

写回前会自动下载一份可导入 Edge 的 HTML 备份。

## 自动整理

在设置中开启后：

- 新增书签约 1 分钟后自动处理
- 可按 30 分钟、2 小时、6 小时或每天执行补漏
- 只处理尚未生成描述的收藏
- 不会覆盖手动修改过的条目
- 删除书签时同步清理对应描述

自动任务只在已配置模型并授权接口域名后运行。

## 权限与隐私

- 分类时只发送标题和网址，不发送原文件夹名
- 不申请 `tabs`、`history`、`scripting`、`<all_urls>` 权限
- 基础权限：`bookmarks`、`storage`、`favicon`、`alarms`
- 模型接口域名在首次调用时按需申请，不预先写入 manifest
- API Key 保存在本机 `chrome.storage.local`，不同步、不上传
- 描述和标签只保存在本机；文件夹结构跟随 Edge 账号同步
- 写回前自动下载 HTML 备份，并保留一次撤销记录

## 技术栈

- WXT 0.21 + Manifest V3
- Vue 3.5 + TypeScript
- Tailwind CSS 4
- `chrome.bookmarks`：读取和修改收藏结构
- `chrome.storage.local`：保存设置、描述和撤销记录
- `chrome.alarms`：后台自动整理
- 原生 `fetch`：直连 OpenAI 兼容接口
- 无后端、无数据库、无截图服务

```
entrypoints/
  dashboard/     工作台（设置也在同一页面内切换）
  background.ts  工具栏入口与自动任务
components/      界面组件
composables/     状态与主题
lib/             分类、模型请求、书签操作、备份、规则
tests/           纯逻辑单元测试
```

## 开发

```powershell

pnpm compile    # vue-tsc 类型检查

pnpm build      # 生产构建到 .output/edge-mv3

```

## 已知限制

- 小模型在冷门站点上可能给出泛化或错误的描述；「待确认」只能覆盖分类缺失、描述过短和低置信度，无法识别所有幻觉
- Edge 收藏 API 没有「描述」字段，因此描述和标签只存在于 tidee 中，不会显示在 Edge 收藏夹里
- 整理后的文件夹结构会同步到同一微软账号的其他设备
- 未打包扩展需要开发者模式；移动目录或重装后需要重新加载
